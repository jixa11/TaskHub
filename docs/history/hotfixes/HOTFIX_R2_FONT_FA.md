# اصلاح فونت نسخه LAN R2

علت تغییر فونت در R1 این بود که فایل `Vazirmatn-Regular.ttf` داخل خروجی PyInstaller قرار نگرفته بود و مرورگر به فونت جایگزین Tahoma برمی‌گشت.

در R2:

- قبل از Build وجود فونت بررسی می‌شود.
- در صورت نبودن فونت، اسکریپت آن را از سورس نسخه 8.0.1 کنار پروژه استخراج می‌کند.
- اگر فونت پیدا نشود Build متوقف می‌شود و دیگر EXE ناقص ساخته نمی‌شود.
- فایل فونت با `--add-data` داخل EXE قرار می‌گیرد.
- نسخه URL فونت برای جلوگیری از کش مرورگر به `8.0.3-lan-r2` تغییر کرده است.

## ساخت

فایل `TaskHub_v8.0.1_source.zip` را کنار پوشه پروژه قرار دهید و سپس `build.bat` را اجرا کنید.
