# اصلاح R3: دسترسی پلنر/مدیر و راهنمای سامانه

- مدیر و پلنر همه پروژه‌ها، تسک‌ها، قراردادها و کاربران را مشاهده می‌کنند.
- مدیر و پلنر شهر، پروژه، دسته‌بندی، قرارداد و اسناد مالی را ثبت/ویرایش می‌کنند.
- مدیریت کاربران عملیاتی برای مدیر و پلنر فعال است؛ نقش‌های admin/manager/planner فقط توسط مدیر سیستم تغییر می‌کنند.
- تفاوت اصلی: تایید نهایی، قفل مالی و بایگانی نهایی قرارداد فقط مدیر/مدیر سیستم.
- راهنمای سامانه کوتاه و نقش‌محور شد و توضیحات فنی قدیمی HTTPS، کلید دستگاه، مهاجرت و نسخه حذف شد.
