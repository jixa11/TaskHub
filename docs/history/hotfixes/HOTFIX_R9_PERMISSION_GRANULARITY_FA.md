# ممیزی ریزدسترسی‌ها — TaskHub 8.0.3 LAN R9

شماره نسخه تغییر نکرده است.

## مدل دسترسی

هر صفحه یا عملیات می‌تواند سه لایه مستقل داشته باشد:

1. نمایش منوی صفحه
2. مشاهده اطلاعات صفحه
3. مجوز عملیات مشخص مانند ثبت، ویرایش، تأیید یا بایگانی

نمونه برای واگذاری فقط بایگانی قرارداد به نقش مالی:

- `menu.contracts` — قراردادها
- `contracts.view` — مشاهده قراردادها
- `contracts.archive` — بایگانی قرارداد

برای این سناریو فعال‌کردن `contracts.manage` لازم نیست.

## موارد اصلاح‌شده

- جداسازی بایگانی قرارداد، الحاقیه و صورت‌وضعیت از مجوز ویرایش یا تأیید
- جداسازی مشاهده، بارگذاری، ویرایش و بایگانی فایل
- جداسازی تأیید الحاقیه و تأیید داخلی صورت‌وضعیت
- کنترل مستقل نظرهای تسک
- کنترل مستقل گزارش‌های مالی و گزارش ظرفیت/کیفیت داده
- اضافه‌شدن کنترل بایگانی تیم و اتصال تیم به پروژه
- الزام هم‌زمان مجوز منو و مجوز مشاهده صفحه
- حذف اثر محدودکننده `data-role` قدیمی وقتی مجوز صریح برای یک کنترل تعریف شده است
- یکسان‌سازی گارد رابط کاربری و API برای عملیات‌های فوق
- محافظت از منطق صورت‌وضعیت‌های مهاجرتی برای جلوگیری از بازگشت درصد پیشرفت مالی به صفر

## محدودیت امنیتی عمدی

`access_control.manage` فقط برای مدیر سیستم باقی مانده و قابل واگذاری به نقش‌های دیگر نیست.

- بررسی Syntax فایل‌های JavaScript با Node.js
- بررسی Compile فایل‌های Python
- اجرای 149 تست خودکار: موفق
- 2 تست مقایسه‌ای به‌دلیل نبود سورس خارجی نسخه 6.2.1 در بسته Skip شدند
