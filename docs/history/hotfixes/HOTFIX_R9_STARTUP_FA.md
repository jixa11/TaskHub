# اصلاح R9: راه‌اندازی مطمئن و جایگزینی نسخه قدیمی

- قبل از اجرای وب‌سرور، مالک پورت 19234 شناسایی می‌شود.
- اگر نسخه قدیمی TaskHub پورت را گرفته باشد، همان نسخه به‌صورت خودکار بسته می‌شود.
- هیچ پردازش غیرمرتبطی به‌صورت خودکار بسته نمی‌شود.
- اگر وب‌سرور بالا نیاید، برنامه با پیام روشن بسته می‌شود و دیگر روی صفر درصد نمی‌ماند.
- نام Mutex بین نسخه‌ها یکسان و مستقل از R1/R3/R7 شده است.
