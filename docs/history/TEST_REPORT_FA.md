- ۲۸ تست واحد و ساختاری: موفق
- ثبت و یکتایی ۱۱۳ مسیر Flask و بارگذاری داده اصلی برای هر ۸ نقش: موفق
- ثبت رکورد جدید پروژه دارای نوع، قرارداد، الحاقیه و صورت‌وضعیت، به‌همراه برنامه مالی و تسک با شمار صحیح پارامترهای SQL: موفق
- رد پروژه بدون نوع و کنترل سمت سرور دسترسی کارشناس مالی، پلنر و پشتیبان: موفق
- سریال‌سازی `row_version` واقعی به شکل bytes در فهرست الحاقیه و صورت‌وضعیت: موفق
- تفکیک مبلغ ارسال‌شده ۶ میلیارد ریال از مبلغ تاییدشده ۳ میلیارد ریال در گزارش مالی: موفق
- ساخت ۷ گزارش Excel و یک گزارش PDF، شامل درآمد پروژه و سهم کارکرد: موفق
- بارگذاری و تبدیل تصویر ۲۴۰۰×۱۸۰۰ و تشخیص فایل تکراری: موفق
- تست DOM شش صفحه، ۱۲ ماه، ۴ فصل، بسته‌ماندن «موارد بیشتر» و مسیر کلیک نوع ← پروژه ← اسناد: موفق
- تست Syntax همه فایل‌های Python و JavaScript و یکپارچگی فیلتر زمانی داشبورد: موفق
- Dry Run کاملاً آفلاین روی سه فایل واقعی مهاجرت: موفق و منطبق با شمارش‌های مورد انتظار
- بررسی آرشیو بکاپ، SHA-256، جلوگیری از Zip Slip و دنبال‌کردن والد بکاپ تفاضلی: موفق
- مقایسه AST تابع `connection_string()` با نسخه ۶.۲.۱: کاملاً یکسان

## محدودیت محیط تست

محیط تحویل Linux است؛ بنابراین ساخت نهایی EXE ویندوز و اتصال به SQL Server عملیاتی شرکت در این محیط انجام نشده است. `build.bat` روی ویندوز پیش از ساخت EXE تست‌های واحد و Flask را اجرا می‌کند و در صورت خطا ساخت را متوقف می‌سازد. پیش از بهره‌برداری، اجرای آزمایشی روی یک کپی دیتابیس و اجرای `sql/validate_v7_after_migration.sql` الزامی است.
