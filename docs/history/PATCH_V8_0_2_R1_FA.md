# اصلاحیه 8.0.2-r1

این اصلاحیه برای دو ایراد رابط کاربری نسخه 8.0.2 تهیه شده است.

## اصلاح فونت

- فونت Vazirmatn از مسیر محلی `/assets/Vazirmatn-Regular.ttf` بارگذاری می‌شود.
- فایل فونت در هر دو خروجی دسکتاپ و سرور PyInstaller بسته‌بندی می‌شود.
- اگر فایل فونت موجود نباشد، `build.bat` متوقف می‌شود تا نسخه ناقص با فونت Tahoma ساخته نشود.
- اسکریپت `prepare_font_from_v801.bat` فایل فونت را از سورس یا ZIP نسخه 8.0.1 موجود روی همان سیستم پیدا و کپی می‌کند.
- Cache و Service Worker به شناسه `8.0.2-r1` ارتقا یافته‌اند تا مرورگر فونت و فایل‌های جدید را حتماً دریافت کند.

## اصلاح داشبورد

فضای خالی به این علت بود که شبکه نمودارها دو ستونه بود اما بعد از افزودن نمودار نوع پروژه، تعداد کارت‌ها فرد شده بود. اکنون چهار کارت تکمیلی در همان شبکه قرار دارند و تعداد کل کارت‌ها هشت مورد است:

1. وضعیت تسک‌ها
2. تسک‌ها بر اساس شهر
3. پروژه‌های پرتسک
4. بار کاری پشتیبان‌ها
5. تسک‌ها بر اساس نوع پروژه
6. درآمد تاییدشده بر اساس شهر
7. درآمد بر اساس نوع قرارداد
8. سهم مالی تحلیلی تیم و فرد

کارت‌های مالی از همان API و همان منطق دسترسی گزارش‌های اصلی استفاده می‌کنند؛ گزارش تکراری ایجاد نشده است. دکمه «گزارش کامل» کاربر را به صفحه اصلی گزارش می‌برد و PDF/Excel از همان صفحه دریافت می‌شود.

نقش کارشناس مالی نیز به API نمودارهای داشبورد اضافه شده تا کارت‌های داشبورد برای این نقش خالی نمانند.

## روش ساخت

1. در پوشه سورس، `prepare_font_from_v801.bat` را یک‌بار اجرا کنید.
2. وجود فایل `Vazirmatn-Regular.ttf` را کنار `build.bat` بررسی کنید.
3. `build.bat` را اجرا کنید.
4. خروجی جدید `dist\\TaskHub_v8_0_2.exe` را اجرا کنید.
5. در اولین بازشدن، Service Worker قدیمی خودکار جایگزین می‌شود. در صورت بازماندن صفحه قبلی، یک بار دکمه «پاک‌سازی نسخه ذخیره‌شده» را بزنید.
