# چک‌لیست تحویل و اجرای TaskHub 8.0.2

## قبل از اجرا

1. نسخه قبلی را از Tray و Task Manager کامل ببندید.
2. از دیتابیس و پوشه `taskhub_data` نسخه پشتیبان کامل بگیرید.
3. نسخه ۸.۰.۲ را در پوشه‌ای جدا Extract کنید.
4. `taskhub_config.example.json` را با نام `taskhub_config.json` کپی و فقط مقادیر واقعی را وارد کنید.
5. برای Build، `build.bat` را اجرا کنید. Build در صورت شکست Unit Test یا Smoke Test متوقف می‌شود.

## اولین اجرای آزمایشی

1. ابتدا روی کپی دیتابیس اجرا کنید.
2. برای شبکه داخلی از `dist\TaskHub_v8_0_2.exe` استفاده کنید.
3. پس از اولین اتصال، `sql\validate_v802.sql` را اجرا کنید؛ این فایل فقط SELECT دارد.
4. کنترل کنید قراردادهای قبلی روی «نوع تعیین نشده» هستند و انواع فروش، توسعه و پشتیبانی فعال‌اند.
5. یک تسک تکمیل‌شده با پروژه، قرارداد همان پروژه، تیم و مسئول ثبت و گزارش سهم مالی را کنترل کنید.
6. PDF و Excel گزارش درآمد و سهم مالی را برای نقش‌های مجاز آزمایش کنید.
7. `TaskHubMigration_v8.exe --apply` برای اجرای معمول نسخه لازم نیست و بدون بررسی Dry Run اجرا نشود.

## انتشار اینترنتی

1. فایل `dist\TaskHubServer_v8_0_2.exe` را روی Windows Server قرار دهید.
2. تنظیمات نمونه `taskhub_config.iis.example.json` را استفاده کنید.
3. IIS + ARR + URL Rewrite و Certificate معتبر دامنه را تنظیم کنید.
4. IIS درخواست HTTPS/443 را به `http://127.0.0.1:19234` Proxy کند.
5. فقط پورت 443 را روی اینترنت باز کنید؛ پورت 19234 نباید Public شود.
6. با `deploy\register_server_task.ps1` اجرای خودکار Server EXE را ثبت کنید.
7. از داخل سرور `http://127.0.0.1:19234/api/ping` و از اینترنت `https://domain/api/ping` را کنترل کنید.

## کنترل نهایی قابلیت‌ها

- Cache نسخه ۸.۰.۱ بدون حذف کلیدهای پیامرسان خودکار به‌روزرسانی شود.
- گفتگوی خصوصی و گروه تیم روی دسکتاپ و موبایل HTTPS تست شود.
- گزارش درآمد فقط همان صفحه موجود را با نماهای نوع پروژه، شهر و نوع قرارداد نشان دهد.
- فهرست قرارداد تسک فقط قراردادهای پروژه انتخاب‌شده را نمایش دهد.
- مدیر/پلنر فقط تیم‌های عضو خود را ببیند و پشتیبان به گزارش مالی دسترسی نداشته باشد.
- سهم چند مسئول بدون Timer به‌صورت مساوی حدس زده نشود و در کیفیت داده هشدار داده شود.
