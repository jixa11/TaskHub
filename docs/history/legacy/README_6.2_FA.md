# راه‌اندازی TaskHub 6.2.0

1. فایل `taskhub_config.example.json` را به `taskhub_config.json` تغییر نام دهید.
2. آدرس سرور، نام دیتابیس و حساب محدود SQL را وارد کنید. حساب `sa` استفاده نشود.
3. برای اتصال Windows Authentication مقدار `TASKHUB_DB_TRUSTED` را `true` قرار دهید و نام کاربری/رمز را حذف کنید.
4. برای اجرای سورس: `pip install -r requirements.txt` سپس `python taskhub.py`.
5. برای ساخت EXE، فایل `build.bat` را اجرا کنید. فایل تنظیمات باید کنار EXE قرار بگیرد.

## متغیرهای مهم
- `TASKHUB_DB_SERVER`، `TASKHUB_DB_NAME`، `TASKHUB_DB_USER`، `TASKHUB_DB_PASSWORD`
- `TASKHUB_SESSION_HOURS` مدت اعتبار نشست؛ پیش‌فرض 16 ساعت
- `TASKHUB_HOST` و `TASKHUB_PORT`؛ پیش‌فرض `0.0.0.0:19234`
- `TASKHUB_BACKUP_DIR` و `TASKHUB_BACKUP_RETENTION_DAYS`

## هشدار ارتقا
رمز SQL Server موجود در نسخه 6.1.0 افشا شده است. پیش از اجرای نسخه جدید، رمز آن حساب را در SQL Server تغییر دهید و یک Login اختصاصی با حداقل مجوز لازم بسازید.


## اصلاح 6.2.1

نقش مدیر در کارتابل و فهرست تسک‌ها به همه تسک‌های کاربران دسترسی مشاهده دارد. نقش پشتیبان همچنان فقط تسک‌های واگذارشده به خودش یا تسک‌هایی که به‌عنوان همکار در آن‌ها حضور دارد مشاهده می‌کند.


## اصلاحات بازنویسی 6.2.1

- `taskhub_config.json` باید کنار `TaskHub.exe` باشد و در نسخه جدید بر متغیرهای محیطی قدیمی اولویت دارد.
- صفحه نشست‌های فعال از مسیر صحیح API استفاده می‌کند.
- فونت فهرست‌های کشویی با فونت اصلی برنامه یکسان شده است.
